# Logbug Frontend WP

این فولدر برای ذخیره‌ی لاگ‌ها، یافته‌ها و گزارش مشکلات بصری پروژه‌های
که در دستور کار اصلی قرار می‌گیرند (Frontend/WP) استفاده می‌شود.

## Workflow

1. کاربر پرامت ارسال می‌کند (مثلاً: fix visual bug in <project> on <url>).
2. agent (OpenCode) با tool `browse` مرورگر Chrome را باز می‌کند.
3. snapshot / screenshot / testing انجام می‌شود.
4. مشکلات بصری شناسایی می‌شود.
5. گزارش در این فولدر ذخیره می‌شود (با نام مربوطه).
