## ۱. معرفی

افزونه امکان نمایش راهنمای سایز و مراقبت در صفحهٔ محصولات ووکامرس را با **تنظیمات کامل و داینامیک** فراهم می‌کند. محتوای هر راهنمای سイズ در ساختار تودرتو ذخیره می‌شود:

```
راهنمای سایز بندی
├── تب ۱ (عنوان + آیکون)
│   ├── آکاردئون ۱ (عنوان + آیکون + محتوای HTML + حالت باز/بسته)
│   └── آکاردئون ۲
└── تب ۲
    └── آکاردئون ۳
```

اگر تنها یک تب وجود داشته باشد، نوار تب‌ها خودکار مخفی می‌شود و محتوای آن به‌صورت آکاردئون نمایش داده می‌شود.

## ۳. معماری و پایگاه داده

### ۳.۱ گزینه‌ها (Options)

همهٔ تنظیمات در یک option با کلید `dssg_options` ذخیره می‌شوند:

| کلید | نوع | پیش‌فرض | توضیح |
|------|-----|---------|-------|
| `version` | string | `1.0.0` | نسخه دیتابیس |
| `enabled` | int | `0` | فعال‌سازی کلی |
| `style` | string | `accordion` | `accordion` / `tabs` / `modal` |
| `enable_mode` | string | `all` | `all` / `cats` / `products` |
| `categories` | array | `[]` | شناسه دسته‌بندی‌ها |
| `products` | array | `[]` | شناسه محصولات |
| `palette` | array |見て siehe默示 | پالت رنگی (primary, secondary, bg, text, muted, border) |
| `tabs` | array |サンプル | ساختار تودرتو تب‌ها و آکاردئون‌ها |

### ۳.۲ متا محصول

هر محصول می‌تواند وضعیت سه‌حالته داشته باشد:

| مقدار | توضیح |
|-------|-------|
| `default` | اتبع تنظیمات عمومی افزونه |
| `yes` | فعال (مصرف-grade غلبه بر تنظیمات دسته‌بندی) |
| `no` | غیرفعال (مصرف-grade غلبه بر تنظیمات دسته‌بندی) |

کلید متا: `_dssg_enable` (ικαřel می‌تواند در هر صفحهٔ ویرایش محصول تغییر یابد).

### ۳.۳ منطق نمایش

راهنمای سایز برای یک محصول نمایش داده می‌شود اگر:

1. سوییچ محصول `yes` باشد → **فعال** (غلبه بر همه)
2. سوییچ محصول `no` باشد → **غیرفعال** (غلبه بر همه)
3. سوییچ محصول `default` باشد → بررسی حالت عمومی:
   - `all` → همه محصولات
   - `cats` → محصول در دسته‌بندی‌های انتخاب‌شده
   - `products` → محصول در لیست محصولات انتخاب‌شده

## ۴. صفحه تنظیمات (سبک DS)

صفحه تنظیمات زیرمنوی ووکامرس است (`woocommerce` → `راهنمای سایز بندی`). slug: `ds-size-guide`.

### ۴.۱ بخش‌ها

| بخش | توضیح |
|------|-------|
| راهنمای سایز بندی | فعال/غیرفعال کلی + شورت‌کد |
| تب و آکاردئون‌ها | ساختار تودرتو محتوای داینامیک |
| استایل و ظاهر | سبک نمایش (آکاردئون/تب/مودال) + پالت رنگی |
| فعال‌سازی و شرایط | حالت فعال‌سازی + دسته‌بندی/محصول |
| راهنمای استفاده | شورت‌کد و هوک‌ها |

### ۴.۲ ساختار فرم

فرم‌های تنظیمات از جدول `form-table` وردپرس و دکمهٔ `submit_button` استفاده می‌کنند. ذخیره از طریق `admin_post_dssg_save` با nonce و بررسی `manage_woocommerce` انجام می‌شود.

## ۵. ساختار محتوای داینامیک

هر تب دارای این فیلدها است:

| فیلد | نوع | توضیح |
|------|-----|-------|
| `id` | string | شناسه یکتا (HTML-safe) |
| `title` | string | عنوان تب |
| `icon` | string | اسlug آیکون (کتابخانه یا `custom`) |
| `custom_icon` | url | آدرس SVG آپلود شده (در صورت `custom`) |
| `items` | array | لیست آکاردئون‌ها |

هر آکاردئون دارای این فیلدها است:

| فیلد | نوع | توضیح |
|------|-----|-------|
| `id` | string | شناسه یکتا |
| `title` | string | عنوان آکاردئون |
| `icon` | string | اسlug آیکون |
| `custom_icon` | url | آدرس SVG آپلود شده |
| `open` | bool | حالت باز در ابتدا |
| `content` | string | محتوای HTML ( escaped با `wp_kses_post` ) |

### ۵.۱ دکمهٔ کپی

در صفحه تنظیمات، دکمهٔ «کپی» برای هر تب و هر آکاردئون موجود است. کپی کل ساختار (شامل آیتم‌های تودرتو) را کلبک می‌کند و بعد از تب/آکاردئون فعلی قرار می‌دهد.

### ۵.۲ محتوای نمونهٔ اولیه

در فعال‌سازی اولین بار، محتوای نمونهٔ همان راهنمای سایز کمربند (جدول ۹ سایز XS تا 5XL، روش اندازه‌گیری، دستور مراقبت) به‌عنوان تب پیش‌فرض درج می‌شود.

## ۶. سبک‌های نمایش

### ۶.۱ آکاردئون (پیش‌فرض)

از `<details>` و `<summary>` استفاده می‌کند. در مرورگرهای مدرن (Chrome 120+)، انیمیشن از طریق `details::details-content` و `transition-behavior: allow-discrete` انجام می‌شود و JavaScript کنار می‌کشد. در مرورگرهای قدیمی‌تر، فالبک Web Animations API است.

### ۶.۲ تب

نوار تب‌ها در بالای محتوای هر تب نمایش داده می‌شود. اگر تنها یک تب وجود داشته باشد، نوار مخفی می‌شود و محتوای مستقیماً نمایش داده می‌شود.

### ۶.۳ مودال (پاپ آپ)

دکمهٔ triggering در صفحهٔ نمایش داده می‌شود. کلیک روی آن، صفحه شفاف (backdrop) و پنل مودال را باز می‌کند. Esc یا کلیک بیرون یا دکمهٔ بستن، مودال را می‌بندد.

## ۷. فرंट‌اند و شورت‌کد

### ۷.۱ شورت‌کد

```
[dssg_guide]
[dssg_guide product_id="123"]
[dssg_guide style="modal"]
```

- `product_id`: شناسه محصول (اختیاری؛ در صفحهٔ محصول، محصول فعلی استفاده می‌شود)
- `style`: جایگزین سبک تنظیمات (اختیاری)

### ۷.۲ هوک قالب

```php
do_action( 'dssg_render_guide', $product_id );
```

### ۷.۳ بارگذاری دارایی‌ها

فایل‌های CSS و JS فقط در صفحهٔ محصول و فقط وقتی که راهنمای سایز برای آن محصول فعال است، بارگذاری می‌شوند.

## ۸. افزودن تنظیمات جدید

.pages و بخش‌های صفحه تنظیمات در `class-dssg-admin.php` تعریف می‌شوند. برای افزودن بخش جدید:

1. کلید بخش را به `$sections` و `current_section()` اضافه کنید.
2. متد `render_{section}_section()` را بنویسید.
3. کلید section را به `$allowed` در `save_settings()` اضافه کنید.
4. در `save_settings()` فیلدهای مربوطه را ذخیره کنید.

فیلدهای جدید باید از `esc_attr` / `esc_html` / `sanitize_text_field` / `absint` / `sanitize_key` استفاده کنند و nonce را تایید کنند.

## ۹. هوک‌ها و فیلترها

| هوک/فیلتر | توضیح |
|-----------|-------|
| `dssg_save` | nonce ذخیره تنظیمات |
| `dssg_elementor_group_id` | شناسهٔ گروه تب المنتور (پیش‌فرض `3d04054`) |
| `dssg_tab_title` | عنوان تب injected (پیش‌فرض `راهنمای سایز و مراقبت`) |

```php
// مثال: تغییر شناسهٔ گروه المنتور بعد از بازسازی قالب
add_filter( 'dssg_elementor_group_id', function () {
    return 'NEW_GROUP_ID';
} );

// مثال: تغییر عنوان تب
add_filter( 'dssg_tab_title', function () {
    return 'راهنمای سایز جدید';
} );
```

## ۱۰. المنتور

### ۱۰.۱ ویجت

ویجت `dssg_guide` در دسته‌بندی `woocommerce` ثبت می‌شود. تنظیمات:
- شناسه محصول (خالی = محصول فعلی)
- سبک نمایش (تنظیمات افزونه / آکاردئون / تب / مودال)
- شناسه HTML (اختیاری)

### ۱۰.۲ تزریق خودکار

اگر قالب استفاده می‌کند از Elementor Atomic Tabs در صفحهٔ تک محصول، افزونه تب راهنمای سایز را به گروه تب‌های producto تزریق می‌کند. شناسهٔ گروه قابل فیلتر است (`dssg_elementor_group_id`).

تاریخچه: استراتژی تزریق از نسخه قبلی (راهنمای کمربند سیمرغ‌سایا) به ارث رسیده است و با ساختار ۰-پایه‌ای Atomic Tabs Elementor سازگار است (شناسه‌ها در runtime از ترتیب DOM بازمحاسبه می‌شوند).

توجه: تزریق در پیش‌نمایش ویرایشگر المنتور انجام نمی‌شود.

## ۱۱. مهاجرت و پایداری

### ۱۱.۱ مهاجرت از نسخه قبلی

در فعال‌سازی، افزونه متاهای `_ssbg_enabled = 'yes'` را به `_dssg_enable = 'yes'` مهاجرت می‌کند و کلید قدیمی را حذف می‌کند.

### ۱۱.۲ حذف افزونه

وقتی افزونه غیرفعال شود، تنظیمات و متاهای محصول حفظ می‌شوند (برای فعال‌سازی مجدد). فقط در uninstall (حذف کامل از پیشخوان)، option `dssg_options` حذف می‌شود.
