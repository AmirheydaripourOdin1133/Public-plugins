راهنمای سایز و مراقبت داینامیک و شخصی‌سازی شده برای محصولات ووکامرس با صفحه تنظیمات اختصاصی، شورت‌کد، ویجت المنتور و تزریق تب المنتور.

== توضیحات ==
افزونه «راهنمای سایز بندی محصولات سفارشی» امکان نمایش راهنمای سایز و مراقبت در صفحهٔ محصولات ووکامرس را با تنظیمات کامل و داینامیک فراهم می‌کند.

امکانات اصلی:
- صفحه تنظیمات اختصاصی در منوی ووکامرس (سبک DS)
- ساختار تودرتو: تب → آکاردئون (هر تب می‌تواند حاوی چند آکاردئون باشد)
- محتوای قابل ویرایش با HTML برای هر آکاردئون
- سه سبک نمایش: آکاردئون (پیش‌فرض)، تب و مودال (پاپ آپ)
- پالت رنگی کامل و هماهنگ با قالب سایت
- کتابخانهٔ آیکون SVG داخلی + امکان آپلود آیکون SVG سفارشی
- دکمهٔ کپی/حذف برای تب و آکاردئون + محتوای نمونهٔ اولیه
- شورت‌کد [dssg_guide product_id="123"]
- ویجت المنتور و تزریق خودکار تب به گروه‌های تب المنتور (Atomic Tabs)
- فعال‌سازی: کلی (همه محصولات) / بر اساس دسته‌بندی / بر اساس محصول انتخاب‌شده + سوییچ سه‌حالته در هر محصول
- مهاجرت خودکار از افزونهٔ قبلی (راهنمای کمربند سیمرغ‌سایا)
- پشتیبانی کامل RTL و ریسپانسیو
- فیلترهای PHP برای توسعه‌دهندگان

== نصب ==
۱. پیشخوان وردپرس ← افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه
۲. فایل ds-size-guide.zip را نصب و فعال کنید. ووکامرس باید فعال باشد.
۳. ووکامرس ← راهنمای سایز بندی ← تنظیمات را انجام دهید.
۴. در صفحهٔ ویرایش محصول، از کادر «راهنمای سایز بندی» وضعیت نمایش را انتخاب کنید.
۵. برای نمایش در هر جای دیگر، از شورت‌کد [dssg_guide] یا ویجت المنتور استفاده کنید.

== استفاده ==
شورت‌کد:
[dssg_guide]
[dssg_guide product_id="123"]
[dssg_guide style="modal"]

هوک‌ها (قالب):
do_action( 'dssg_render_guide', $product_id );
