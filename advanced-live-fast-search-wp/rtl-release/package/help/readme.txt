راهنمای کوتاه — جستجوی زنده پیشرفته وردپرس

1) فایل داخل پوشه Plugin را نصب کنید: advanced-live-fast-search-wp.zip
2) افزونه را فعال کنید.
3) دامنه را در حساب راست‌چین ثبت کنید.
4) از منوی «جستجوی زنده» وضعیت لایسنس را بررسی کنید.
5) منابع را انتخاب، کش را بازسازی، و شورت‌کد [mfs_search] را قرار دهید.
