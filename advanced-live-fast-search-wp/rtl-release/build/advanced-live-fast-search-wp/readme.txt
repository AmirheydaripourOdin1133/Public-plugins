جستجوی زنده پیشرفته تیزجو برای وردپرس و ووکامرس؛ کش JSON سمت سرور و جستجوی سمت کاربر.

== Description ==

* جستجوی زنده بدون هیچ درخواست AJAX هنگام تایپ
* کش JSON سمت سرور با بازسازی خودکار پس از تغییر محتوا
* انتخاب منابع جستجو: پست‌تایپ و تکسونومی عمومی
* چهار اسکین آماده: مودال، نوار جستجو، پنل بالا و پنل دو ستونه
* پشتیبانی از قیمت و تخفیف ووکامرس
* نرمال‌سازی حروف فارسی و پنل تنظیمات فارسی
* لایسنس رسمی راست‌چین

Usage: place `[mfs_search]` in your header (or `<?php echo mfs_search(); ?>` in PHP).
