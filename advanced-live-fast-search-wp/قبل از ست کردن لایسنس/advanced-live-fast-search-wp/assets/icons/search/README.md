# آیکون‌های جستجو (پکیج قابل انتخاب)

فایل‌های SVG را با همین نام‌ها جایگزین کنید:

| فایل | تنظیمات |
|------|---------|
| `search-1.svg` | سبک ۱ |
| `search-2.svg` | سبک ۲ |
| `search-3.svg` | سبک ۳ |
| `search-4.svg` | سبک ۴ |

قوانین:
- `viewBox="0 0 24 24"` (همان سایز تریگر مودال)
- برای رنگ از `stroke="currentColor"` یا `fill="currentColor"` استفاده کنید
- رنگ ثابت (`#000` و …) نگذارید تا اکسنت تنظیمات اعمال شود

مسیر کامل از ریشهٔ پلاگین:
`assets/icons/search/`
